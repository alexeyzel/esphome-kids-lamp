# Меню нічника: прошивання та перевірка

## Файли й версія

ESPHome **2026.10.0 або новіший**. Для ESPHome Device Builder достатньо короткого YAML із [examples/home-assistant.yaml](../examples/home-assistant.yaml): він завантажує конфігурацію через `packages`, а заголовки меню — через `external_components` із GitHub. Вручну копіювати `.h` файли до Home Assistant більше не потрібно. Повна інструкція — у [README](../README.md).

Заголовки зберігаються в `components/kids_lamp/`. Мінімальний Python-адаптер лише підключає їх до збірки штатним завантажувачем ESPHome; логіку меню та драйвери обладнання не змінено.

Секрети залишаються у власному `secrets.yaml`; перелік ключів — у `secrets.yaml.example`. Для локальної перевірки використано окремі тестові значення у `.validation/`, не реальні облікові дані. Прошивку з тестовими секретами не встановлювати на пристрій.

Перевірка та збірка з власними секретами:

```powershell
esphome config kids-night-lamp.yaml
esphome compile kids-night-lamp.yaml
esphome upload kids-night-lamp.yaml
```

## Ревізія дисплея

Офіційна документація M5Stack повідомляє про зміну GC9107 на ST7735 від 2026-05-14. Ревізію саме наявного пристрою ще не перевірено. За замовчуванням налаштовано **ST7735**. Якщо після прошивання є підсвічування, але немає правильного зображення, перевірити ревізію та профіль.

Для старої ревізії у `substitutions` змінити:

```yaml
lcd_model: GC9107
lcd_pad_y: '1'
```

Решта параметрів залишається: offsets 2/1, rotation 180, invert true — відповідно до профілю GC9107 в ESPHome та прикладу M5Stack ESPHome. Це профіль ESPHome, його параметри не слід механічно замінювати параметрами іншої графічної бібліотеки. Для ST7735 використано RAM 132×132: видима область 128×128, offsets 2/1, padding 2/3 за геометрією офіційного M5GFX. Орієнтацію та кольори перевірити на обладнанні.

Підсвічування — LP5562, I²C 0x30, білий канал; SDA GPIO45, SCL GPIO0. Кнопка — GPIO41, SPI екрана — CLK15, MOSI21, CS14, DC42, RESET48. Схема підключення LED не змінюється: GPIO1 → кільце Поліни → кільце Германа.

Параметри `screen_active_pwm: '80'` і `screen_idle_pwm: '3'` задають PWM дисплея з діапазону 0–255. Їхню комфортність треба перевірити вночі. Кольори палітри визначені на початку `components/kids_lamp/lamp_controls.h`; теплий білий поки RGB 100/35/5%. Обмеження максимальної яскравості кілець не додано.

## Перевірка на пристрої

1. Після запуску обидва кільця вимкнені, екран показує вибір лампи. LED 0–7 — Поліна, 8–15 — Герман.
2. Коротке натискання змінює вибір лише після вікна 350 мс. Утримання 700 мс відкриває меню; відпускання не виконує коротку дію. Смуга знизу показує утримання.
3. У меню коротке гортатиме колір → яскравість → живлення. Довге на кольорі/яскравості вмикає тільки вибрану лампу без зміни значення. Подальші короткі змінюють значення; довге повертає до меню.
4. Подвійне з підменю повертає до вибору лампи без зміни світла. Подвійне на виборі вимикає обидві, якщо хоча б одна ввімкнена; інакше вмикає обидві з індивідуальними налаштуваннями. Не повинно бути додаткового одиночного перемикання.
5. У HA з'являються два RGB-світильники та кнопки «Увімкнути обидва»/«Вимкнути обидва». Стара спільна сутність світла може залишитися недоступною в реєстрі HA; її можна видалити після перевірки нових.
6. Через HA встановити 42%: дисплей показує 42%, наступний короткий у яскравості дає 50%. Встановити червоний: екран показує фактичний колір без виділення пресета, наступний короткий у кольорі дає теплий білий. Зміна іншої лампи не змінює навігацію.
7. Через 30 с без кнопки з'являється тьмяна іконка. Зміни з HA не будять екран. Перше натискання лише відкриває вибір; цілий жест пробудження (також довге або подвійне) поглинається.
8. Встановити різні кольори/яскравості, зачекати щонайменше 5 с, перезапустити. Обидві лампи вимкнені; ввімкнення повертає їхні індивідуальні налаштування. При різкому зникненні живлення в межах 5 с остання зміна може не встигнути записатися у flash.
9. Вимкнути HA та Wi-Fi довше ніж на 15 хв: меню й обидві лампи керуються локально, автоматичного перезавантаження через втрату з'єднання немає. Перевірити повернення керування з HA після відновлення зв'язку.
10. Перевірити реальну яскравість, нагрівання та струм на потрібних режимах; окремо оцінити видимість заставки у темряві.

## Автоматична перевірка розробки

Перевірено на ESPHome 2026.10.0: YAML для обох профілів дисплея валідний; ST7735 повністю зібрано для ESP32-S3. RAM 107439 байтів (31.4%), Flash 928779 байтів (23.6%). Використано тестові секрети; ці бінарні файли призначені лише для перевірки збірки.

`tests/lamp_controls_test.cpp` — автономні C++ тести натискань, пробудження, таймауту, переповнення millis(), яскравості й палітри. Пройдено локальним Zig C++ компілятором. Приклад для звичайного C++ компілятора:

```text
c++ -std=c++17 -Wall -Wextra -Werror tests/lamp_controls_test.cpp -o lamp_controls_test
```
