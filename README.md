# ESPHome Kids Lamp

Нічник для двох дітей на M5Stack AtomS3R і двох WS2812B-кільцях по 8 LED. Окремі світильники «Нічник Поліни» та «Нічник Германа», меню з іконками через передню кнопку, тьмяна заставка й керування через Home Assistant.

## Установлення через Home Assistant

Потрібен ESPHome **2026.10.0 або новіший**. У редакторі YAML наявного пристрою `kids-night-lamp` замінити конфігурацію на:

```yaml
packages:
  kids_night_lamp:
    url: https://github.com/alexeyzel/esphome-kids-lamp
    ref: main
    files: [kids-night-lamp.yaml]
    refresh: 0s
```

Скопійований варіант: [examples/home-assistant.yaml](examples/home-assistant.yaml). У власному `secrets.yaml` залишити ключі `wifi_ssid`, `wifi_password`, `api_encryption_key`, `fallback_ap_password`; назви й приклади — у [secrets.yaml.example](secrets.yaml.example). Справжні секрети в репозиторій не додавати.

Натиснути **Validate**, потім **Install** звичним способом. ESPHome сам завантажить YAML-пакет і допоміжні C++ заголовки через `external_components`. Окремо створювати або копіювати `.h` файли в Home Assistant не потрібно. Зібрана прошивка працює без доступу до GitHub, HA або Wi-Fi; інтернет потрібен під час завантаження джерел для збірки.

`refresh: 0s` перевіряє зміни в GitHub під час наступної перевірки/збірки. Це не запускає автоматичне оновлення нічника. Для фіксації версії замінити `ref: main` на потрібний commit SHA та додати в локальний YAML `substitutions: {project_ref: ТОЙ_САМИЙ_SHA}`, щоб YAML і заголовки бралися з однієї версії.

## Дисплей

За замовчуванням вибрано **ST7735**. Для старої ревізії AtomS3R із **GC9107** додати до локального YAML:

```yaml
substitutions:
  lcd_model: GC9107
  lcd_pad_y: '1'
```

Ревізію конкретного пристрою та зображення потрібно перевірити на обладнанні. Параметри яскравості дисплея, натискань і таймауту можна перевизначати через локальний `substitutions`. Див. [перевірки на стенді](docs/testing-menu.md).

## Керування

- Коротке натискання: наступна лампа, пункт меню або значення.
- Довге (700 мс): увійти у вибраний пункт; у налаштуванні значення — повернутися до меню. На пункті живлення — перемкнути вибрану лампу.
- Подвійне: з підменю повернутися до вибору лампи; на виборі лампи вимкнути обидві, якщо хоча б одна ввімкнена, інакше ввімкнути обидві.
- Після 30 с бездіяльності — тьмяна іконка; жест пробудження лише відкриває вибір лампи.
- HA: два RGB-світильники та кнопки «Увімкнути обидва» і «Вимкнути обидва».
- Після перезавантаження обидві лампи вимкнені, колір і яскравість відновлюються. Запис налаштувань у flash відкладений до 5 с.

Повні вимоги: [рішення 002](docs/decisions/002-atom-menu-controls.md).

## Структура та перевірки

- `kids-night-lamp.yaml` — повна конфігурація з Git-завантаженням заголовків.
- `components/kids_lamp/` — заголовки меню та малювання і мінімальний Python-адаптер для завантаження через штатний механізм ESPHome; власних драйверів обладнання немає.
- `examples/home-assistant.yaml` — короткий YAML для Device Builder.
- `tests/lamp_controls_test.cpp` — автономні тести обробника натискань.

```text
esphome config kids-night-lamp.yaml
esphome compile kids-night-lamp.yaml
c++ -std=c++17 -Wall -Wextra -Werror tests/lamp_controls_test.cpp -o lamp_controls_test
```

На обладнання встановлювати тільки збірку зі своїми секретами. Бінарні файли локальної перевірки з тестовими секретами не публікуються.
