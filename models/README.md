# 3D models / 3D-моделі

The completed lamp enclosure slips over the bed end of an IKEA GULLIVER bed with a very tight fit. Upload the existing enclosure, diffuser and mounting models here; CAD files are not included yet.
Корпус завершеного нічника надягається на спинку IKEA GULLIVER з дуже щільною посадкою. Завантажуйте сюди наявні моделі корпусу, розсіювача та кріплень; CAD-файли поки не додано.

- `STEP` / `STP`: editable exchange geometry / геометрія для редагування.
- `F3D`: Fusion 360 source / вихідна модель Fusion 360.
- `STL` / `3MF`: printable models / моделі для друку.

Use descriptive names and revisions, for example `diffuser-v01.stl`. Document units (prefer mm), dimensions, material, print orientation, supports and fit checks alongside each model. Remove author names, local paths and other personal metadata from CAD/3MF exports before uploading.

Використовуйте зрозумілі назви та версії, наприклад `diffuser-v01.stl`. Поруч зазначайте одиниці (бажано мм), розміри, матеріал, орієнтацію друку, підтримки та результати примірки. Перед завантаженням видаляйте імена авторів, локальні шляхи та інші персональні метадані з CAD/3MF.
